# Здоров’я, безпека та добробут, 6 клас

Інтерактивний конспект для Лізи за підручником Н. Гущиної та І. Василашко «Здоров’я, безпека та добробут»
за ред. Т. Бойченко (Видавничий дім «Освіта», 2023). Перша половина книжки: § 1–9 і два підсумкові тести
(після розділів 1 і 2). Кожен параграф — конспект, терміни, малюнки з підручника, шість врізок
(Черкащина, Україна, Гоґвортс, коні, з життя, з гри) і 8 питань з автоперевіркою.

Локально — подвійний клік по `course/index.html`. Онлайн: https://liza-school.github.io/zbd-6/

Зроблено за зразком «Географії», «Природи» й «Зарубіжної літератури»: той самий рушій, ті самі блоки.
Помилки підручника — червоні блоки на сторінках і реєстр `course/tools/errata.json`.
PDF підручника в репозиторій не входить.

Перевірка перед тим, як віддавати: `cd course && node tools/check.js`
